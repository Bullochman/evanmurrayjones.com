Already imported the old DDI calendar?

That was a one-time file, so it can't update and its times are now wrong. Remove it one of two ways:

  1. Import the removal file: remove-old-ddi-calendar.ics. Open it on the device where you imported the old file and add it to the same calendar. In Apple Calendar and Outlook this cancels the old events.
  2. Or delete them by hand: find any old event (Marshal's Guard, Zombie Siege, Desert Storm Team A or B, Meteorite Iron War) and delete it, choosing "Delete all future events" when asked. If you imported the old file into its own calendar, just delete that whole calendar.

Then subscribe above. Google Calendar ignores removal files, so on Google delete the old events by hand.
